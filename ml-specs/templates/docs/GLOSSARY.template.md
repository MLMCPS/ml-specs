# Glossary

> Domain vocabulary for this project: the term, what it means **here**, and what it is not to be
> confused with. Optional — a project without one is not missing anything, and no command fails
> because it is absent.
>
> Seeded by `/ml-specs:repo-init`, refreshed by `/ml-specs:repo-refresh`. Neither overwrites prose
> a human wrote.

## Why this file and not `CLAUDE.md`

`CLAUDE.md` is a thin index: it points, it does not inline. A glossary is the opposite shape —
entries read on demand, when a term in a spec or a diff is ambiguous. Keeping them apart is the
division that stops the two files duplicating each other.
